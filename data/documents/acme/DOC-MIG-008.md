# DOC-MIG-008 — Migration Policy (Synthetic)

SYNTHETIC DOCUMENT

1. Production critical systems require architecture review before migration wave entry.
2. Systems with unresolved critical dependencies cannot enter Wave 1.
3. Unsupported runtimes (VB6, end-of-support frameworks) require remediation or retire/replace decisions.
4. Sensitive databases require security review before replatform/refactor.
5. Rehost is acceptable for low-coupling batch utilities; customer payment paths prefer replatform or refactor with evidence.
